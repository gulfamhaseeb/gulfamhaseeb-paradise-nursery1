# Paradise Nursery

Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.
Visitors can browse plants by category, add them to a shopping cart, adjust
quantities, remove items, and see the running total.

## Features
- Landing page with a "Get Started" button
- Plant listing grouped into three categories (6 plants each)
- "Add to Cart" buttons that disable once a plant is in the cart
- Navbar with Home, Plants and Cart links and a live cart item count
- Cart page with per-plant subtotals, quantity controls, delete, grand total,
  a "Checkout" button (Coming Soon) and "Continue Shopping"

## Run locally
```bash
npm install
npm run dev
```

## Tech
React 18, Redux Toolkit, React-Redux, Vite
